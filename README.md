# AI Gym CRM Dashboard

A responsive AI-powered CRM dashboard designed for gyms and fitness businesses.

## Features

- Dashboard Overview
- Lead Management
- Lead Search
- Lead Filtering
- AI Lead Scoring
- Notification Bell
- Analytics Dashboard
- Program Management
- Responsive Design

## Tech Stack

- React
- TypeScript
- Vite
- Git
- GitHub
- Cursor AI

## Project Overview

This project simulates a modern CRM system for gyms and fitness centers. It helps manage leads, track trial sessions, monitor revenue, and prioritize prospects using AI-inspired lead scoring and recommendations.

### Dashboard Features

- Total Leads Tracking
- Hot Lead Identification
- Trial Session Monitoring
- Revenue Dashboard
- AI Recommendation Notifications
- Lead Search and Filtering
- Analytics Charts
